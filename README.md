# 📊 Excel Data Analysis Projects

## 📌 Project: Employee Database Analysis

This repository contains my Excel-based data analysis practice projects.  
The main objective of this project is to analyze employee data using Excel functions and extract meaningful insights.

## 🗂 Dataset Description

The dataset includes the following fields:

- Date  
- Employee ID  
- Employee Name  
- Designation  
- KRA (Key Responsibility Area)  

The data was converted into CSV format and analyzed in Microsoft Excel.

## 🎯 Problems Solved

1. Calculated total number of employees  
2. Counted total Sales Executives  
3. Counted Sales Executives working for Amazon and Myntra  
4. Retrieved Designation and KRA using lookup functions  
5. Fetched Employee ID using VLOOKUP

## 🛠 Excel Functions Used

- COUNTIF  
- COUNTIFS  
- SUMIF  
- VLOOKUP  
- INDEX + MATCH  
- TRIM (for removing extra spaces)  
## 📈 Key Learnings

- Handling structured employee datasets  
- Applying conditional counting using COUNTIFS  
- Using lookup functions for dynamic data retrieval  
- Improving problem-solving using Excel formulas  
- Performing basic business data analysis
